# Занятия и оплаты — CRM онлайн-школы английского

Учёт занятий, абонементов и денег. Заменяет файл «Отчет по учителям.xlsx»,
в котором одни и те же данные лежали на десяти листах и расходились между собой.

Сайт: https://rutasha2809-creator.github.io/crm-english-school/

## Как устроено

Вручную вносятся три факта и ничего больше:

1. **Начисление за месяц** — строка на ученика в таблице «Начисления и оплаты»:
   занятия, цена, скидка в процентах, подарок в рублях и фактическая оплата.
2. **Проведённое занятие** — отметка в журнале. Занятие группы отмечается один раз.
3. **Выплата педагогу** — дата и сумма.

Родители платят за месяц вперёд. Количество занятий к оплате считается само:
занятий по плану минус неиспользованный остаток. Кнопка «Начислить всем по плану»
заполняет всю таблицу разом, дальше любую строку можно поправить.

Остаток правится прямо в ячейке — так вносятся занятия, перенесённые с месяцев,
которых в программе нет. Поправка хранится отдельной строкой с нулевой суммой,
поэтому не попадает ни в выручку, ни в долг родителя.

Сумма к оплате = занятия × цена − скидка, % − подарок, ₽. Скидка считается
от стоимости занятий, подарок вычитается уже из неё: это подарок за приведённых
клиентов. Фактическую оплату можно вписать любую — долг пересчитается.

Всё остальное считается само:

| Показатель | Как считается |
|---|---|
| Остаток занятий у ученика | начислено занятий минус посещённые и пропуски с оплатой |
| Долг родителя | начислено минус поступило |
| Начислено педагогу | проведённые занятия × его ставка |
| Долг перед педагогом | начислено минус выплачено |
| Заработок школы | начислено родителям минус начислено педагогам |

## Справочники

Заполняются один раз и редко меняются:

| Справочник | Что в нём |
|---|---|
| Учителя | ФИО и банковские реквизиты для выплат |
| Ученики | имя и родитель; видно, в какой группе ученик или что занимается индивидуально |
| Группы | педагог, ставка педагога, тариф ученика, календарь занятий, состав |
| Индивидуальные занятия | то же самое для учеников вне групп: педагог, ставка педагога, тариф ученика, календарь занятий |
| Тарифы клиентам | цена одного занятия для ученика |
| Тарифы педагогов | сколько школа платит педагогу за одно занятие |

Ученик состоит максимум в одной группе и берёт от неё педагога, дни занятий
и ставку педагога. Связь появляется сразу в обеих карточках.
Переименование в справочнике безопасно: ссылки на старое название обновляются
сами, а уже проданные абонементы не меняются — в них цена зафиксирована.

## Экраны

| Экран | Что делает |
|---|---|
| Месяц | Продано, получено, начислено педагогам, заработок; остаток занятий и долг по каждому ученику |
| Журнал занятий | Сетка «занятия × дни месяца»: строка группы — само занятие, строки учеников под ней — кто был |
| Расписание по дням | Кто и у кого занимается в каждый день месяца |
| Начисления и оплаты | Таблица начислений за месяц с оплатами, выплаты педагогам, кто не доплатил, сколько должны педагогам |
| Отчёты | Финансовый итог по месяцам, долги родителей, свод по педагогам; выгрузка в Excel |
| Справочники | Учителя, ученики, группы, индивидуальные занятия, тарифы клиентам, тарифы педагогов |

Расписание задаётся календарём: в карточке группы или индивидуального занятия
отмечаются конкретные даты месяца. Кнопка «Повторить прошлый месяц» переносит
расписание по тем же дням недели, дальше даты правятся поштучно.

Кнопка «Подтвердить план по сегодня» отмечает проведёнными все прошедшие
занятия по плану — в обычный месяц это и есть вся работа.

Состояния клетки в журнале по кругу: пусто → план → проведено →
отмена с оплатой → отмена без оплаты.

Строка группы отвечает за само занятие: по ней считается выплата педагогу —
один раз за занятие, независимо от числа учеников. Строки учеников под ней
отвечают за посещение: по умолчанию ученик идёт за группой, а отметка в его
строке — исключение, «не пришёл» или «пропустил с оплатой». Поэтому пропуск
одного ученика уменьшает его остаток и не трогает ни группу, ни педагога.

## Стек

Чистые HTML, CSS и JS без сборки. Данные — в Postgres на Supabase,
вход по email и паролю, доступ к строкам ограничен политиками RLS:
каждый видит только свои данные.

| Файл | Назначение |
|---|---|
| `index.html` | Разметка, подключение библиотек |
| `app.css` | Стили, светлая и тёмная темы |
| `app.js` | Вся логика: расчёты, экраны, работа с Supabase |
| `config.js` | Адрес проекта Supabase и публичный ключ |

Публичный ключ в `config.js` лежит в открытом виде намеренно: сам по себе он
доступа к данным не даёт, его ограничивают вход и политики RLS.

## Таблицы

Все с префиксом `oe_`, в общем проекте Supabase с «Фрилабом»; данные проектов
не пересекаются.

| Таблица | Содержимое |
|---|---|
| `oe_teachers` | Педагоги: банковские реквизиты, памятки по платежу |
| `oe_units` | Ученики и группы: педагог, ставка педагога, тариф ученика, связь «ученик ↔ группа» |
| `oe_months` | Одна строка на «ученик или группа + месяц»: план и отметки занятий по дням |
| `oe_subscriptions` | Начисления: месяц, количество занятий, цена, скидка, подарок, сумма |
| `oe_payments` | Деньги: оплаты родителей и выплаты педагогам |
| `oe_settings` | Тарифы клиентам, тарифы педагогов, абонементы |
