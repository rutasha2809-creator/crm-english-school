# Занятия и оплаты — CRM онлайн-школы английского

Учёт занятий, абонементов и денег. Заменяет файл «Отчет по учителям.xlsx»,
в котором одни и те же данные лежали на десяти листах и расходились между собой.

Сайт: https://rutasha2809-creator.github.io/crm-english-school/

## Как устроено

Вручную вносятся три факта и ничего больше:

1. **Начисление** — кому, когда, сколько занятий и на какую сумму.
   Количество и сумма фиксируются в момент начисления и дальше не меняются,
   даже если потом поменяются тарифы.
2. **Проведённое занятие** — отметка в журнале. Занятие группы отмечается один раз.
3. **Движение денег** — оплата от родителя или выплата педагогу.

Всё остальное считается само:

| Показатель | Как считается |
|---|---|
| Остаток занятий у ученика | начислено занятий минус проведено |
| Долг родителя | начислено минус поступило |
| Начислено педагогу | проведённые занятия × его ставка |
| Долг перед педагогом | начислено минус выплачено |
| Заработок школы | начислено родителям минус начислено педагогам |

Ручных полей «занятий к оплате» и «перенос» нет: непроведённые занятия просто
остаются в остатке и переходят на следующий месяц сами.

Родители платят за месяц вперёд, поэтому на экране «Начисления и оплаты» первым идёт
начисление на следующий месяц: занятий по плану минус неиспользованный остаток —
ровно столько занятий осталось оплатить. Кнопка «Начислить» подставляет ученика
и это количество в форму начисления, остаётся выбрать абонемент; сумма считается
по его цене занятия и скидке от подставленного количества.

Остаток в этой таблице редактируется прямо в ячейке: так вносятся занятия,
перенесённые с месяцев, которых в программе нет. Разница сохраняется отдельной
строкой с нулевой суммой, поэтому не попадает ни в выручку, ни в долг родителя.

Фактическая сумма предоплаты вносится в «Движение денег» — любая сумма и дата,
частичная оплата допустима: долг родителя это продано минус поступило.

## Справочники

Заполняются один раз и редко меняются:

| Справочник | Что в нём |
|---|---|
| Учителя | ФИО и банковские реквизиты для выплат |
| Ученики | имя и родитель; видно, в какой группе ученик или что занимается индивидуально |
| Группы | педагог, ставка педагога, дни занятий, состав |
| Индивидуальные занятия | то же самое для учеников вне групп: педагог, ставка педагога, дни занятий |
| Тарифы клиентам | цена одного занятия для ученика |
| Тарифы педагогов | сколько школа платит педагогу за одно занятие |
| Абонементы | заготовка для начисления: тариф, количество занятий, скидка |

Ученик состоит максимум в одной группе и берёт от неё педагога, дни занятий
и ставку педагога. Связь появляется сразу в обеих карточках.
Переименование в справочнике безопасно: ссылки на старое название обновляются
сами, а уже проданные абонементы не меняются — в них цена зафиксирована.

## Экраны

| Экран | Что делает |
|---|---|
| Месяц | Продано, получено, начислено педагогам, заработок; остаток занятий и долг по каждому ученику |
| Журнал занятий | Сетка «ученики × дни месяца»; клик по клетке меняет состояние занятия |
| Расписание по дням | Кто и у кого занимается в каждый день месяца |
| Начисления и оплаты | Начисление на следующий месяц, начисления (можно сразу всей группе), оплаты и выплаты, кто не доплатил, сколько должны педагогам |
| Отчёты | Финансовый итог по месяцам, долги родителей, свод по педагогам; выгрузка в Excel |
| Справочники | Учителя, ученики, группы, индивидуальные занятия, тарифы клиентам, тарифы педагогов, абонементы |

Расписание задаётся днями недели, поэтому план на любой месяц строится сам.
Кнопка «Подтвердить план по сегодня» отмечает проведёнными все прошедшие
занятия по плану — в обычный месяц это и есть вся работа.

Состояния занятия в журнале: план → проведено → отмена с оплатой →
отмена без оплаты → снято с плана.

## Стек

Чистые HTML, CSS и JS без сборки. Данные — в Postgres на Supabase,
вход по email и паролю, доступ к строкам ограничен политиками RLS:
каждый видит только свои данные.

| Файл | Назначение |
|---|---|
| `index.html` | Разметка, подключение библиотек |
| `app.css` | Стили, светлая и тёмная темы |
| `app.js` | Вся логика: расчёты, экраны, работа с Supabase |
| `config.js` | Адрес проекта Supabase и публичный ключ |

Публичный ключ в `config.js` лежит в открытом виде намеренно: сам по себе он
доступа к данным не даёт, его ограничивают вход и политики RLS.

## Таблицы

Все с префиксом `oe_`, в общем проекте Supabase с «Фрилабом»; данные проектов
не пересекаются.

| Таблица | Содержимое |
|---|---|
| `oe_teachers` | Педагоги: банковские реквизиты, памятки по платежу |
| `oe_units` | Ученики и группы: педагог, ставка, дни недели, связь «ученик ↔ группа» |
| `oe_months` | Одна строка на «ученик или группа + месяц»: отметки занятий по дням |
| `oe_subscriptions` | Начисления: дата, количество занятий, сумма |
| `oe_payments` | Движение денег: оплаты родителей и выплаты педагогам |
| `oe_settings` | Тарифы клиентам, тарифы педагогов, абонементы |
