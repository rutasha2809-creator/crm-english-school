# Занятия и оплаты — CRM онлайн-школы английского

Учёт занятий педагогов, оплат от родителей и выплат педагогам. Заменяет файл
«Отчет по учителям.xlsx», в котором одни и те же данные лежали на десяти листах
и расходились между собой.

Сайт: https://rutasha2809-creator.github.io/crm-english-school/

## Как устроено

Вручную заполняются только справочники: тарифы клиентам, тарифы педагогов,
учителя, ученики и абонементы. Абонемент — это название, вид занятий из тарифов
клиентам, количество занятий и скидка; его стоимость считается сама.

Тарифы педагогов — такой же список, как тарифы клиентам: название и ставка за
занятие. Ставка назначается группе или индивидуальному ученику; ученик в группе
берёт её от группы.

В карточке ученика выбираются учитель и абонемент. Ученик состоит максимум
в одной группе: когда его добавляют в группу из списка учеников, связь
появляется в обеих карточках, а учитель и дни занятий он берёт от группы.

Переименование в справочнике безопасно: все ссылки на старое название
обновляются автоматически. В отчётах месяц учитывается, только если по нему
что-то вносили, иначе абонемент подставлял бы суммы в пустые месяцы.

Начисление идёт по абонементу ученика и всегда один раз, даже если он в группе.
Педагогу школа платит за фактически проведённые занятия, причём занятие группы
считается один раз, а не по числу учеников. Заработок школы — разница между
начисленным и выплатами.

| Экран | Что делает |
|---|---|
| Месяц | Начислено, получено, остаток, выплаты педагогам и заработок школы по каждому ученику |
| Журнал занятий | Сетка «ученики × дни месяца». Клик по клетке меняет состояние занятия |
| Расписание по дням | Кто и у кого занимается в каждый день месяца |
| Абонементы и оплаты | Абонемент каждого ученика, оплаты родителей, перенос занятий, выплаты педагогам |
| Отчёты | Финансовый итог по месяцам, долги родителей, свод по педагогам; выгрузка в Excel |
| Справочники | Учителя, ученики, группы, тарифы клиентам, тарифы педагогов, абонементы |

Расписание задаётся днями недели, поэтому план на любой месяц строится сам.
Кнопка «Подтвердить план по сегодня» отмечает проведёнными все прошедшие
занятия по плану — в обычный месяц это и есть вся работа.

Состояния занятия в журнале: план → проведено → отмена с оплатой →
отмена без оплаты → снято с плана.

Абонемент в справочнике задаётся названием, видом занятий, количеством занятий
и скидкой. Стоимость урока подтягивается из тарифов клиентам по виду занятий,
стоимость абонемента считается как количество занятий × стоимость урока минус
скидка.

## Стек

Чистые HTML, CSS и JS без сборки. Данные — в Postgres на Supabase,
вход по email и паролю, доступ к строкам ограничен политиками RLS:
каждый видит только свои данные.

| Файл | Назначение |
|---|---|
| `index.html` | Разметка, подключение библиотек |
| `app.css` | Стили, светлая и тёмная темы |
| `app.js` | Вся логика: расчёты, экраны, работа с Supabase |
| `config.js` | Адрес проекта Supabase и публичный ключ |

Публичный ключ в `config.js` лежит в открытом виде намеренно: сам по себе он
доступа к данным не даёт, его ограничивают вход и политики RLS.

## Таблицы

Все с префиксом `oe_`, в общем проекте Supabase с «Фрилабом»; данные проектов
не пересекаются.

| Таблица | Содержимое |
|---|---|
| `oe_teachers` | Педагоги: ставки, банковские реквизиты, памятки по платежу |
| `oe_units` | Ученики и группы: абонемент, дни недели, связь «ученик ↔ группа» |
| `oe_months` | Одна строка на «ученик + месяц»: отметки по дням и абонементы (занятий, перенос, цена, оплата) |
| `oe_payouts` | Одна строка на «педагог + месяц»: запрошено, выплачено, дата |
| `oe_settings` | Тарифы клиентам, тарифы педагогов, абонементы |
